# STEMBridge AI — Project Brief

## Goal
Build an AI-powered STEM career exploration and learning platform.

## Target users
Students who want to discover STEM careers and learn the skills needed for those careers.

## MVP Features
1. Interest-based STEM career recommendations.
2. Personalized step-by-step learning roadmaps.
3. Curated and verifiable educational resources.
4. Follow-up questions about a selected learning path, if time permits.

## Primary user journey
Enter interests -> Get career suggestions -> Select career
-> Generate learning roadmap -> View resources.

## Technology
- Next.js with TypeScript
- Tailwind CSS
- Next.js server-side API routes
- Google Gemini API
- Curated resource catalog

## Constraints
- Solo developer.
- Build within a 48-hour target.
- No authentication or database in MVP.
- Never expose API keys.
- Use existing AI models.
- Prioritize functionality over visual complexity.
- Build and submit original work.

## Success Criteria
A student can complete the main workflow in a public deployed application.
